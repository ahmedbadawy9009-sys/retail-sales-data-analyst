
# 📊 Retail Store Sales & Customer Behavior Analytics

An end-to-end Data Analytics portfolio project analyzing sales performance and customer purchasing behavior across retail chain stores using **Excel**, **SQL**, **Python**, and **Power BI**.

---

## 📌 Project Overview
This project evaluates retail transactions to identify key revenue drivers, high-value customer segments, product categories, and monthly sales trends.

---

## 🛠️ Tools & Technologies
* **Data Processing:** Microsoft Excel
* **Database Querying:** PostgreSQL / MySQL
* **Statistical Analysis & Forecasting:** Python (Pandas, Scikit-Learn)
* **Interactive Dashboards:** Power BI

---

## 💡 Key Business Insights
* **Electronics Category:** Contributed over 42% of total retail revenue.
* **Geographical Growth:** Top demand concentrated in Cairo and Alexandria regions.
* **Customer Retention:** Identified repeat buyer patterns to optimize marketing reach.
